 FlavorGram - Recipe Finder
A beautiful recipe management app to discover, create, and share delicious recipes with stunning visuals.

## 🚀 Live Demo

- **Frontend**: https://flavorgram-recipe-finder.netlify.app
- **Backend API**: https://flavorgram-recipe-finder.onrender.com

✨ Features
📸 Image Uploads - Add photos to your recipes

🔍 Smart Search - Find recipes by name or ingredients

📱 Responsive Design - Works on all devices

❤️ Like Recipes - Save your favorites

🎨 Beautiful UI - Smooth animations and modern design

🛠️ Tech Stack
Frontend: React, CSS3, JavaScript
Backend: Node.js, Express, MongoDB
Deployment: Netlify, Render, MongoDB Atlas

📦 Quick Start
bash
# Clone the repository
git clone https://github.com/MICHEAL7400/FlavorGram-Recipe-Finder.git

# Install dependencies
npm install

# Start development server
npm start
Visit http://localhost:3000 to view the app.

🎯 API Endpoints
GET /api/recipes - Get all recipes

POST /api/recipes - Create new recipe

PUT /api/recipes/:id - Update recipe

DELETE /api/recipes/:id - Delete recipe

POST /api/recipes/:id/like - Like a recipe
